# 抢码器 FrameCode

Windows 10/11 x64 的直播房间码识别工具。特调用来无畏契约抢码，上航航车，抢鸡脚筋。它播放直播或采集桌面窗口，在本地识别房间码，稳定确认后自动复制；也可以自动粘贴并点击加入。应用无需登录、注册或会员。

## 主要功能

- 支持直播、本地视频和桌面 / 窗口画面识别。
- 识别成功后自动复制房间码，可选自动粘贴并加入。
- 支持保存识别区域，切换到游戏或最小化后继续识别。
- 文字识别在本地完成。

## 下载与使用

适用于 Windows 10 / 11，64 位系统。解压即可运行，无需安装。

1. 从 [Releases](../../releases/latest) 下载发布包并解压。
2. 右键 `FrameCode.exe`，选择“以管理员身份运行”。
3. 连接直播、打开本地视频，或选择“桌面 / 窗口画面”。
4. 框选房间码所在区域，并选择对应的识别规则。
5. 按 `Ctrl + 1` 开始识别，成功后房间码会自动复制到剪贴板。

框选时尽量只包含房间码文字。常用区域可保存为预设，方便下次使用。

## 自动粘贴并加入

1. 在 FrameCode 中勾选“自动粘贴并加入”。
2. 将游戏切到前台，把鼠标移到游戏的“粘贴”按钮上，按 `Ctrl + 2` 记录位置。
3. 把鼠标移到“加入”按钮上，按 `Ctrl + 3` 记录位置。
4. 保持游戏在前台，按 `Ctrl + 1` 开始识别。

三角洲规则无需记录粘贴按钮；开始前请先点击游戏的房间码输入框。

在“操作设置”中点击“快速参数”，再点击“保存设置”，可将三项等待设为 **10 / 20 / 50 ms**。无畏契约双按钮操作的固定等待由 230 ms 降至 110 ms；三角洲 Ctrl+V 模式由 155 ms 降至 80 ms。这些数值不含识别、Windows 调度和游戏响应耗时。如果出现漏点或粘贴未完成，可切回“稳妥参数”（30 / 45 / 80 ms），也可手动调整。升级会保留已保存的参数。

**自动操作需以管理员身份运行。** 每次重启后，请重新启用自动操作并记录位置。建议使用窗口化或无边框模式；移动游戏窗口后请重新记录。首次使用时先核对按钮位置，按 `Ctrl + Shift + Q` 可随时停止。

如需始终以管理员身份运行：右键 `FrameCode.exe` →“属性”→“兼容性”→勾选“以管理员身份运行此程序”→“应用”。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + 1` | 开始 / 停止识别 |
| `Ctrl + 2` | 记录粘贴按钮位置 |
| `Ctrl + 3` | 记录加入按钮位置 |
| `Ctrl + Shift + Q` | 紧急停止 |

## 识别规则

| 规则 | 房间码格式 |
| --- | --- |
| 无畏契约特调 | 3 个字母 + 3 位数字 |
| 三角洲特调 | 3 个字母 + 4 位数字 |
| 三角洲 1V1 特调 | 4 个字母 + 4 位数字 |
| 通用六位码 | 6 位大写字母或数字 |
